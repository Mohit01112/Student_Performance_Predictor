📊 About the Project

🎓 Student Performance Prediction System

An AI-powered educational analytics platform that predicts student mathematics performance using machine learning models and a scalable data science pipeline. The system also integrates an intelligent AI Tutor Chatbot that assists students by answering academic questions and explaining concepts interactively.

🎯 Project Overview

The Student Performance Prediction System is a machine learning web application designed to predict a student's mathematics score based on demographic and academic factors such as gender, parental education level, lunch type, test preparation course, reading score, and writing score.

Trained machine learning models analyze these inputs to generate accurate predictions. A Flask-based web interface allows users to easily enter student details and instantly view prediction results along with performance insights.

In addition to predictive analytics, the platform includes a built-in AI Tutor Chatbot that allows students to ask questions related to mathematics, data science, or academic topics directly from the web interface. The chatbot provides real-time explanations and learning assistance, making the system both a prediction tool and an interactive educational assistant.

The project demonstrates an end-to-end machine learning system, combining data processing, model training, and real-time prediction through a production-style data science pipeline. The architecture reflects real-world ML engineering practices used in industry, including data ingestion and preprocessing, feature engineering and transformation, model training and evaluation, an automated prediction pipeline, and deployment via a web application.

⚙️ How the System Works

  1. 1️⃣ Data Collection: The dataset contains student information such as gender, race/ethnicity, parental level of education, lunch type, test preparation course, reading score, and writing score. These features are used as inputs to predict the mathematics score.
  2. 2️⃣ Data Processing: The dataset is prepared using preprocessing techniques such as handling missing values, encoding categorical features, and applying feature scaling/normalization so that the models can learn effectively.
  3. 3️⃣ Model Training: Multiple machine learning algorithms are trained and evaluated, including Random Forest Regressor, Decision Tree Regressor, Gradient Boosting Regressor, Linear Regression, XGBoost Regressor, CatBoost Regressor, and AdaBoost Regressor. The best model is selected based on R² score performance.
  4. 4️⃣ Prediction Pipeline: When a user submits student details through the web interface, the trained model is loaded from the artifacts, the input is preprocessed using the transformation pipeline, and the predicted mathematics score is generated and displayed on the results page.
  5. 5️⃣ AI Tutor Interaction: Students can also interact with the AI Tutor Chatbot to ask questions related to mathematics or academic topics, enabling personalized learning support alongside prediction insights.

🎓 Student Assistance Classification

🟢 No Assistance Needed

Score ≥ 60 → The student is performing well (Excellent / Good) and typically does not require additional academic support.

🟡 Needs Support

Score 40 – 59 → The student may require additional academic support and focused guidance.

🔴 Needs Significant Help

Score < 40 → The student may need strong academic assistance and early intervention to improve performance.

📂 Project Architecture

  • Core Application: app.py – handles Flask web routes and prediction logic.
  • Machine Learning Pipeline: src/components – modules for data ingestion, data transformation, and model training.
  • Prediction Pipeline: src/pipeline – loads the trained model and preprocessor for real-time predictions.
  • Artifacts: artifacts/ – stores trained models and processed datasets.
  • Notebooks: notebook/ – Jupyter notebooks used for EDA and experimentation.
  • Templates: templates/ – HTML pages used by the Flask web interface.
  • Logs: logs/ – system logs for monitoring and debugging.

📡 System Architecture

The system is designed using a modular machine learning architecture inspired by production AI systems:

  • User Input (Student Data) → Flask Web Application
  • Flask Web Application → Prediction Pipeline
  • Prediction Pipeline → Load Preprocessing Pipeline
  • Preprocessing Pipeline → Load Trained ML Model
  • ML Model → Generate Predicted Math Score
  • Predicted Score → Performance Classification
  • Final Output → Display Results on Web Interface

🤖 AI Tutor Chatbot

In addition to score prediction, the application includes an integrated AI Tutor chatbot that helps students understand mathematical and data science concepts directly from the web interface. A floating chat button is available on every page, opening a conversational window where users can ask questions.

  • Frontend: Floating chatbot UI built into the base template, accessible from all pages.
  • Backend API: A dedicated endpoint /api/tutor receives user questions and returns AI-generated answers in JSON.
  • LLM Provider: Uses the Groq Python SDK with the llama-3.1-8b-instant model for fast, high‑quality educational responses.
  • Configuration: The Groq API key is securely loaded from a .env file via python-dotenv and never exposed to the frontend.
  • Use Case: Acts as an interactive study assistant, explaining topics, suggesting resources, and guiding students step‑by‑step.

🧠 AI Model Explanation

The system evaluates several regression algorithms and selects the best-performing model for deployment:

  • Random Forest Regressor
  • Decision Tree Regressor
  • Gradient Boosting Regressor
  • Linear Regression
  • XGBoost Regressor
  • CatBoost Regressor
  • AdaBoost Regressor

Models are evaluated using the R² score and error metrics, and the best-performing model is serialized as a model artifact. This artifact is then loaded by the prediction pipeline inside the Flask app to generate real-time predictions.
