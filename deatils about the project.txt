Project Name: Student Performance Prediction System

Overview:
This project predicts student mathematics scores using machine learning and provides a Flask web interface to make predictions and view results.

Root Files and Folders:

- app.py
  - Type: Python file
  - Function: Main Flask web application. Defines routes for the home page, about page, project description page, and prediction form. Uses the trained ML model (via PredictPipeline) to predict math scores and renders HTML templates (index, about, project, predict, result, error).

- requirements.txt
  - Type: Text file
  - Function: Lists all Python dependencies required to run the project (Flask, scikit-learn, pandas, numpy, CatBoost, XGBoost, etc.).

- setup.py
  - Type: Python file
  - Function: Package configuration script. Allows the project to be installed as a Python package (e.g., using `pip install -e .`).

- README.md
  - Type: Markdown documentation
  - Function: High-level documentation of the project, including overview, features, tech stack, project structure, installation steps, usage, model performance, and contact details.

- .gitignore
  - Type: Git configuration file
  - Function: Specifies files and folders that Git should ignore (e.g., virtual environment, logs, artifacts, compiled files).

- artifacts/ (folder)
  - Function: Stores data and model artifacts produced by the ML pipeline.
  - Important contents:
    - data.csv: Raw dataset saved after ingestion.
    - train.csv: Training split of the dataset.
    - test.csv: Test split of the dataset.
    - model.pkl: Serialized best-trained ML model (created by ModelTrainer).
    - proprocessor.pkl: Serialized preprocessing object (created by DataTransformation).

- logs/ (folder)
  - Function: Stores log files generated by the application and training scripts.
  - Contents:
    - Files named like YYYY-MM-DD_HH-MM-SS.log
    - Each log file records steps, info messages, and errors during data ingestion, transformation, model training, and prediction.

- notebook/ (folder)
  - Function: Contains Jupyter notebooks used for exploratory data analysis and model experimentation.
  - Important contents:
    - 2. MODEL TRAINING.ipynb: Notebook showing data exploration, model training experiments, and evaluation for student performance prediction.
    - data/ (inside notebook): Contains the original dataset file stud.csv used by DataIngestion.

- src/ (folder)
  - Function: Main source code for the ML pipeline and utilities.

  - src/components/ (folder)
    - data_ingestion.py
      - Function: Handles loading the raw dataset and splitting it into training and testing sets.
      - Key behavior:
        - Reads stud.csv from notebook/data/.
        - Saves raw data to artifacts/data.csv.
        - Splits data into train and test sets using train_test_split.
        - Saves train.csv and test.csv into artifacts/.

    - data_transformation.py
      - Function: Preprocesses the data and builds the preprocessing pipeline.
      - Key behavior:
        - Defines a ColumnTransformer with:
          - Numerical pipeline (for writing_score, reading_score) using median imputation and StandardScaler.
          - Categorical pipeline (gender, race_ethnicity, parental_level_of_education, lunch, test_preparation_course) using most-frequent imputation, OneHotEncoder, and StandardScaler.
        - Fits the preprocessor on training data and transforms both training and test features.
        - Combines transformed features with the target (math_score) into numpy arrays.
        - Saves the fitted preprocessor as artifacts/proprocessor.pkl.

    - model_trainer.py
      - Function: Trains and selects the best regression model.
      - Key behavior:
        - Defines ModelTrainerConfig with path artifacts/model.pkl.
        - Evaluates multiple models: RandomForestRegressor, DecisionTreeRegressor, GradientBoostingRegressor, LinearRegression, XGBRegressor, CatBoostRegressor, AdaBoostRegressor.
        - Uses R² score on the test set to choose the best model.
        - Saves the best model to artifacts/model.pkl.

  - src/pipeline/ (folder)
    - train_pipeline.py
      - Function: Orchestrates the full ML training pipeline.
      - Key behavior:
        - Creates a DataIngestion instance and runs initiate_data_ingestion() to get train and test CSV paths.
        - Creates a DataTransformation instance and runs initiate_data_transformation() to get processed train/test arrays and preprocessor path.
        - Creates a ModelTrainer instance and runs initiate_model_trainer() to train and evaluate models.
        - Logs the final R² score and returns it.
        - Can be run as a script to (re)train the model.

    - predict_pipeline.py
      - Function: Provides utilities for making predictions from new data.
      - Key behavior:
        - PredictPipeline:
          - Loads artifacts/model.pkl and artifacts/proprocessor.pkl using src.utils.load_object.
          - Applies the preprocessor to input features and runs model.predict to produce predicted math scores.
        - CustomData:
          - Encapsulates a single student's input data (gender, race_ethnicity, parental_level_of_education, lunch, test_preparation_course, reading_score, writing_score).
          - Exposes get_data_as_data_frame() to convert the data into a pandas DataFrame suitable for the pipeline.

  - src/utils.py
    - Function: Helper functions for saving and loading Python objects.
    - Key behavior:
      - save_object(file_path, obj): Creates directories if needed and serializes Python objects to disk using dill.
      - load_object(file_path): Loads and returns Python objects serialized with dill.

  - src/exception.py
    - Function: Custom exception handling.
    - Key behavior:
      - error_message_detail(): Builds a detailed error message including file name and line number.
      - CustomException: Custom exception class that formats error messages and integrates with logging.

  - src/logger.py
    - Function: Central logging configuration.
    - Key behavior:
      - Creates a logs/ directory if it does not exist.
      - Configures Python logging to write INFO-level logs to a timestamped log file.

- templates/ (folder)
  - Function: Contains HTML templates used by the Flask app (Jinja2 templates).

  - base.html
    - Function: Base layout for all pages (header, footer, styles).
    - Used by: index.html, about.html, project.html, predict.html, result.html, error.html.

  - index.html
    - Function: Home page of the web app.
    - Shows project overview, key features, and navigation buttons to prediction, about, and project pages.

  - predict.html
    - Function: Prediction form page.
    - Contains HTML form inputs for gender, race/ethnicity, parental education, lunch, test preparation, reading score, and writing score.
    - Sends POST request to /predict route when the user submits the form.

  - result.html
    - Function: Results page.
    - Displays predicted mathematics score, performance category (Excellent, Good, Needs Support, Needs Significant Help), emoji, and full student profile summary.
    - Provides recommendations and navigation back to home or new prediction.

  - about.html
    - Function: About the author page.
    - Shows detailed information about the project author, skills, education, contact links, and professional summary.

  - project.html
    - Function: About the project page.
    - Describes the technical architecture, data pipeline, ML models, performance metrics, input features, and overall impact.

  - error.html
    - Function: Error display page.
    - Shown when an exception occurs during prediction. Displays the error message and provides buttons to retry prediction or go home.

- venv/ (folder)
  - Function: Python virtual environment for this project.
  - Contains installed packages, Python binaries, and environment-specific configuration.
  - Managed by Python’s venv module; you usually do not edit files here manually.

- __pycache__/ (folder)
  - Function: Stores compiled Python bytecode files generated automatically when modules are imported.
  - Improves performance but is not edited directly.

Summary:
This project is an end-to-end ML system for predicting student math scores. The src/components and src/pipeline modules handle data ingestion, preprocessing, model training, and prediction. The Flask app (app.py) exposes this functionality through a user-friendly web interface using HTML templates in the templates/ folder. Artifacts, logs, and notebooks support training, debugging, and experimentation.
